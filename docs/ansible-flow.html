Ansible Execution Flow — deploy_combined.yml

Single entry point — auto-detects deploy mode from each intent file path
Color legend
Start / End
Ansible action / decision logic
Decision point
API call to APIC
Auto-detection rules
  • /vrfs/ /bridge_domains/ /epgs/ /application_profiles/ /contracts/ → deploy_mode=main
  • /static_paths/ → deploy_mode=static_path
  • /vpc_policy_groups/ → deploy_mode=vpc
Example command
ansible-playbook playbooks/deploy_combined.yml \
  -e deploy_env=sandbox \
  -e tenant_path=intent/sandbox/tenants/TEST-TENANT \
  -e "intent_files=intent/.../vrfs/TEST-VRF.yml,intent/.../bridge_domains/TEST-BD.yml,intent/.../static_paths/HOST01-eth1-1.yml" \
  -e change_id=CHG-001
